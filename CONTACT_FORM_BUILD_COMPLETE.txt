  • className?: string              Additional CSS classes
  • showPhone?: boolean             Show phone field (default: false)
  • showCompany?: boolean           Show company field (default: false)
  • showSubscribe?: boolean         Show newsletter checkbox (default: true)

1. IDLE (Default)
   - All fields enabled and ready for input
   - Button text: "Send Message"
   - Button is clickable

2. LOADING (Submitting)
   - All input fields are disabled
   - Button text changes to "Sending..."
   - Button is disabled (can't click)
   - Prevents duplicate submissions
   - Visual feedback via disabled state

3. SUCCESS
   - Green success alert appears with message
   - Form fields are automatically reset
   - Alert contains: "Thank you!" + confirmation message
   - Alert automatically dismisses after 5 seconds
   - onSuccess callback is triggered (if provided)

4. ERROR
   - Red error alert appears at top of form
   - Clear error message is displayed
   - Form data is preserved (user can retry)
   - Field-specific errors show inline
   - User can correct and resubmit
